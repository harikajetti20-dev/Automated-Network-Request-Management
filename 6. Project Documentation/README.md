# Automated Network Request Management

**Institution:** NADIMPALLI SATYANARAYANA RAJU INSTITUTE OF TECHNOLOGY (NSRIT)

## Project Overview

Automated Network Request Management is a ServiceNow-based project designed to streamline network request submission, validation, approval, and tracking. It aims to improve the efficiency and visibility of network request management.
